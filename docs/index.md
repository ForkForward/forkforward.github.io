# ForkForward

**Open code. Moving forward.**

ForkForward continues open-source libraries after their original line of development stops being open. We start
from the last version published under a permissive licence, keep its history and its credits, and keep it
building on current platforms.

- **Developed with AI tools.** Changes are written by AI coding tools and automation.
- **Reviewed by people.** A named maintainer reviews every change and decides what is released.
- **Credit stays with the authors.** Every project says which library it continues, who wrote it, and under which
  licence. Original copyright and licence notices are never removed.
- **Independent.** ForkForward is not affiliated with, sponsored by, or endorsed by the authors of the projects it
  continues. If you want their newer versions or commercial support, use the official project.
- **Clean origin.** Nothing is copied from versions released after a licence change.

## Finding our repositories

Repositories are named `<ecosystem>-<project>`, in lower case: `dotnet-`, `js-`, `python-`, `jvm-`, `go-`, `rust-`.

Every repository carries the topic `forkforward`, a technology topic and a function topic. GitHub leaves forks out
of search results unless you ask for them, so search like this:

```
org:ForkForward topic:dotnet fork:true
```
